# Подключение к бэкенду

## Текущая конфигурация

Проект настроен для работы с бэкендом по адресу: **http://85.239.55.179:8000**

## Как это работает

### В режиме разработки (npm run dev)

1. Vite проксирует все запросы с `/api/*` на `http://85.239.55.179:8000`
2. Это позволяет обойти проблемы с CORS
3. Все API запросы идут через прокси: `http://localhost:5173/api/*` → `http://85.239.55.179:8000/*`

### В production (npm run build)

1. API запросы идут напрямую на `http://85.239.55.179:8000`
2. Убедитесь, что бэкенд доступен по этому адресу

## Измененные файлы

- `vite.config.ts` - включен proxy на новый адрес бэкенда
- `src/utils/apiClient.ts` - обновлен API_BASE_URL на новый адрес
- `LOCAL_DEV.md` - обновлены примеры с новым адресом

## Проверка подключения

1. Запустите dev-сервер: `npm run dev`
2. Откройте консоль браузера (F12)
3. Попробуйте войти в систему
4. В консоли должны быть логи API запросов вида:
   ```
   [API] POST /login { hasToken: false, url: '/api/login' }
   ```

## Если нужно изменить адрес бэкенда

### Вариант 1: Через переменную окружения

Создайте файл `.env` в папке `frontend`:

```env
VITE_API_URL=http://новый-адрес:8000
```

### Вариант 2: Изменить в коде

1. `vite.config.ts` - измените `target` в proxy
2. `src/utils/apiClient.ts` - измените дефолтный URL в `API_BASE_URL`

## Отключение бэкенда (локальный режим)

Если нужно работать без бэкенда:

1. В `vite.config.ts` закомментируйте секцию `proxy`
2. В `apiClient.ts` установите:
   ```typescript
   const API_BASE_URL = import.meta.env.VITE_API_URL || (import.meta.env.DEV ? null : 'http://85.239.55.179:8000');
   const LOCAL_DEV_MODE = import.meta.env.DEV && !API_BASE_URL;
   ```

См. подробности в `LOCAL_DEV.md`
