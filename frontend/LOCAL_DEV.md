# Локальная разработка без бэкенда

## Текущая конфигурация

Проект настроен для работы **без бэкенда** в режиме локальной разработки.

### Что изменено:

1. **vite.config.ts** - Proxy на удаленный сервер закомментирован
2. **apiClient.ts** - Добавлен режим локальной разработки с мок-данными
3. API запросы возвращают пустые данные или мок-данные вместо реальных запросов к серверу

## Как это работает

- При запуске `npm run dev` приложение работает локально
- Все API запросы перехватываются и возвращают пустые/мок данные
- В консоли браузера будут предупреждения о локальном режиме
- Авторизация работает в мок-режиме (можно "войти" с любыми данными)

## Включение бэкенда обратно

Когда нужно подключиться к реальному бэкенду:

### Вариант 1: Через переменную окружения

Создайте файл `.env` в папке `frontend`:

```env
VITE_API_URL=http://85.239.55.179:8000
```

### Вариант 2: Через proxy в vite.config.ts

Раскомментируйте proxy в `frontend/vite.config.ts`:

```typescript
server: {
  proxy: {
    '/api': {
      target: 'http://85.239.55.179:8000',
      changeOrigin: true,
      secure: false,
      rewrite: (path) => path.replace(/^\/api/, '')
    }
  }
}
```

И измените в `apiClient.ts`:

```typescript
const API_BASE_URL = import.meta.env.VITE_API_URL || (import.meta.env.DEV ? '/api' : 'http://85.239.55.179:8000');
const LOCAL_DEV_MODE = false; // Отключить локальный режим
```

## Запуск

```bash
# Из корня проекта
npm run dev

# Или из папки frontend
cd frontend
npm run dev
```

Приложение будет доступно на `http://localhost:5173`
