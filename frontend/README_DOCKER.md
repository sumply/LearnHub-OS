# Запуск фронтенда через Docker Compose

Этот проект использует Docker Compose для удобного запуска фронтенда.

## Требования

- Docker (версия 20.10 или выше)
- Docker Compose (версия 2.0 или выше)

## Быстрый старт

1. **Скопируйте файл с переменными окружения:**
   ```bash
   cp .env.example .env
   ```

2. **Отредактируйте `.env` файл:**
   - Укажите URL вашего бэкенд API в переменной `VITE_API_URL`
   - При необходимости измените порт фронтенда в `FRONTEND_PORT`

3. **Запустите контейнер:**
   ```bash
   docker-compose up -d
   ```

4. **Откройте в браузере:**
   - По умолчанию: http://localhost:3000
   - Или порт, указанный в `FRONTEND_PORT`

## Остановка

```bash
docker-compose down
```

## Пересборка после изменений

Если вы внесли изменения в код или переменные окружения, пересоберите образ:

```bash
docker-compose up -d --build
```

**Важно:** Если вы изменили `VITE_API_URL` в `.env`, обязательно пересоберите образ, так как эта переменная используется во время сборки (build time), а не во время выполнения.

## Просмотр логов

```bash
docker-compose logs -f frontend
```

## Переменные окружения

### `VITE_API_URL`
URL бэкенд API сервера. **Эта переменная используется во время сборки образа**, поэтому при её изменении нужно пересобрать образ.

Примеры:
- Локальный бэкенд: `http://localhost:8000`
- Удаленный бэкенд: `http://188.225.24.208:8000`
- Бэкенд в Docker сети: `http://backend:8000` (если бэкенд запущен в той же Docker сети)

**Примечание:** Если бэкенд запущен на той же машине, но вне Docker, используйте `http://host.docker.internal:8000` для доступа из контейнера к хосту.

### `FRONTEND_PORT`
Порт, на котором будет доступен фронтенд. По умолчанию: `3000`

## Интеграция с бэкендом

Если бэкенд также запущен через Docker Compose, вы можете:

1. Добавить бэкенд сервис в `docker-compose.yml`
2. Использовать имя сервиса вместо `localhost` в `VITE_API_URL`
3. Оба сервиса будут в одной сети и смогут общаться друг с другом

Пример:
```yaml
services:
  backend:
    # ... конфигурация бэкенда
  
  frontend:
    # ... конфигурация фронтенда
    environment:
      - VITE_API_URL=http://backend:8000
```

## Устранение неполадок

### Порт уже занят
Измените `FRONTEND_PORT` в `.env` файле на другой порт.

### Не могу подключиться к бэкенду
- Убедитесь, что `VITE_API_URL` указан правильно
- Проверьте, что бэкенд запущен и доступен
- Если бэкенд в Docker, убедитесь, что оба контейнера в одной сети

### Изменения не применяются
Пересоберите образ: `docker-compose up -d --build`

### Изменил VITE_API_URL, но изменения не работают
Переменная `VITE_API_URL` используется во время сборки образа. После изменения её в `.env` файле обязательно выполните:
```bash
docker-compose up -d --build
```
