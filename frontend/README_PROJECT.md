## Структура проекта

- `src/pages/` — основные страницы (Dashboard, Profile, Quiz, AdminDashboard, TeacherDashboard и др.)
- `src/components/` — переиспользуемые компоненты (Header, NavBar, AvatarUploader, AccessibilitySettings и др.)
- `src/config/` — конфиги тестов, пользователей, предметов, групп
- `src/contexts/` — ThemeContext и другие глобальные контексты
- `src/utils/` — вспомогательные сервисы и функции
- `public/fonts/` — кастомные шрифты

## Основные страницы и компоненты

- **Dashboard** — главная страница пользователя
- **Profile** — личный кабинет (аватарка, личные данные, история тестов, редактирование для админа)
- **Quiz** — прохождение тестов (выбор, открытые вопросы, результат, сохранение истории)
- **AdminDashboard** — админ-панель (ученики по классам, преподаватели, переход к ЛК любого пользователя)
- **TeacherDashboard** — кабинет учителя (успеваемость классов, проверка работ)
- **Header, NavBar** — навигация, переключение тем, доступ к профилю
- **AvatarUploader** — загрузка и отображение аватарки

## Темизация и стили

- Использование CSS-переменных для цветов, скруглений, теней, шрифтов
- ThemeContext: переключение темы, high-contrast, масштабирование
- Глобальный шрифт TT Hoves Pro Trial Expanded Medium для кнопок и заголовков
- Прозрачные и скруглённые блоки, современный UI

## Система тестирования

- Тесты описаны в `src/config/activities.ts` (поддержка автопроверки и ручной проверки)
- Компонент Quiz: выбор вариантов, открытые вопросы, сохранение результатов
- История тестов хранится в localStorage, отображается в профиле
- Учитель может проверять работы, выставлять баллы и комментарии

## Профиль пользователя

- Аватарка (загрузка, хранение в localStorage)
- Личные данные, современный стиль, иконки, скругления
- История тестов с детализацией, статусами, комментариями
- Для админа: редактирование всех полей, управление группами и предметами (для учителя), удаление пользователя

## Админ-панель

- Просмотр учеников по классам, переход к ЛК ученика
- Таблица преподавателей: ФИО, email, предметы, классы, кнопка перехода к ЛК учителя
- Добавление, редактирование, удаление пользователей

## Работа с localStorage

- Все изменения профиля, истории, аватарок, тестов — мгновенно сохраняются в localStorage
- При обновлении страницы данные не теряются

## Расширяемость и кастомизация

- Легко добавлять новые роли, предметы, группы, тесты, карточки
- Гибкая структура конфигов и компонентов
- Современный UI, легко интегрировать новые фичи
