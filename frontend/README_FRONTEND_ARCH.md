# Архитектура и современные решения фронтенда

## Общая структура

- **Фреймворк:** SolidJS + TypeScript
- **Стили:** CSS-модули, переменные, поддержка темизации (светлая/тёмная тема)
- **Хранение данных:** localStorage для профилей, истории, аватарок, результатов тестов
- **Роутинг:** @solidjs/router
- **Организация кода:**
  - `src/pages/` — основные страницы (личный кабинет, тесты, админка и т.д.)
  - `src/components/` — переиспользуемые компоненты (Header, NavBar, AvatarUploader и др.)
  - `src/config/` — конфиги тестов, пользователей, предметов, групп
  - `src/contexts/` — контексты для темизации и глобальных настроек
  - `src/utils/` — вспомогательные функции и сервисы
  - `public/fonts/` — кастомные шрифты (TT Hoves Pro и др.)

## Современные решения и подходы

- **Темизация:**
  - Использование CSS-переменных для цветов, скруглений, теней, шрифтов
  - Переключение темы через ThemeContext, хранение выбора в localStorage
  - Поддержка high-contrast режима и масштабирования интерфейса
- **Глобальные шрифты:**
  - TT Hoves Pro Trial Expanded Medium для кнопок и заголовков
  - Подключение через @font-face и использование в глобальных стилях
- **UI/UX:**
  - Прозрачные и скруглённые блоки, современные карточки, адаптивность
  - Кастомные аватарки, drag&drop, инлайн-редактирование профиля
  - Модальные окна для подтверждений и редактирования
- **Роли и доступ:**
  - Разделение интерфейса и логики по ролям (ученик, учитель, родитель, админ)
  - Админ может просматривать и редактировать ЛК любого пользователя
- **Система тестирования:**
  - Поддержка автопроверки и ручной проверки (open/choice вопросы)
  - Сохранение истории тестов, комментарии учителя, статус "на проверке"
- **Локальное хранение:**
  - Все изменения профиля, истории, аватарок и т.д. — мгновенно в localStorage
- **Расширяемость:**
  - Легко добавлять новые роли, предметы, группы, тесты, карточки
  - Гибкая структура конфигов и компонентов

## Интересные моменты реализации

- Использование SolidJS signals для реактивности и производительности
- Минимум глобального состояния, максимум локальной изоляции
- Чистый и современный UI без лишних зависимостей
- Простая интеграция новых фич без переписывания архитектуры
