# Дизайн и Доступность - Лицей Платформа

## 🎨 Новый дизайн

### Основные особенности:
- **Современный минималистичный дизайн** с плавными переходами
- **Адаптивная верстка** для всех устройств
- **Система CSS переменных** для легкого управления темами
- **Улучшенная типографика** с лучшей читаемостью

### Цветовая палитра:
- **Светлая тема**: Чистые белые фоны с синими акцентами
- **Темная тема**: Темно-серые фоны с яркими акцентами
- **Высокий контраст**: Черно-белая схема для людей с нарушениями зрения

## ♿ Функции доступности

### Настройки доступности
Доступны через кнопку с иконкой настроек в правом верхнем углу хедера:

#### 1. Размер текста
- Диапазон: 12px - 24px
- Сохраняется в localStorage
- Применяется ко всему интерфейсу

#### 2. Масштаб интерфейса
- Диапазон: 80% - 150%
- Масштабирует весь интерфейс
- Полезно для людей с нарушениями зрения

#### 3. Темная тема
- Переключение между светлой и темной темой
- Автоматическое сохранение выбора
- Улучшенная читаемость в условиях низкой освещенности

#### 4. Высокий контраст
- Максимальный контраст между элементами
- Рекомендуется для людей с нарушениями зрения
- Черно-белая цветовая схема

#### 5. Быстрые кнопки
- **Сброс текста**: Возврат к размеру 16px
- **Сброс масштаба**: Возврат к 100%

## 🔧 Техническая реализация

### Структура файлов:
```
src/
├── contexts/
│   └── ThemeContext.tsx     # Контекст для управления темами
├── components/
│   ├── Header.tsx           # Обновленный хедер
│   └── AccessibilitySettings.tsx  # Панель настроек доступности
└── index.css               # Обновленные стили с CSS переменными
```

### CSS переменные:
```css
:root {
  --bg-primary: #ffffff;        /* Основной фон */
  --bg-secondary: #f8f9fa;      /* Вторичный фон */
  --text-primary: #212529;      /* Основной текст */
  --accent-primary: #0d6efd;    /* Основной акцент */
  --scale: 1;                   /* Масштаб */
  --font-size-base: 16px;       /* Базовый размер шрифта */
}
```

### Поддерживаемые темы:
1. **Светлая** (по умолчанию)
2. **Темная** (`[data-theme="dark"]`)
3. **Высокий контраст** (`[data-high-contrast="true"]`)
4. **Темная + высокий контраст** (`[data-theme="dark"][data-high-contrast="true"]`)

## 🚀 Использование

### Для разработчиков:
1. Все стили используют CSS переменные
2. Темы переключаются через `data-theme` атрибут
3. Масштаб контролируется через `--scale` переменную
4. Размер шрифта через `font-size` на `html` элементе

### Для пользователей:
1. Нажмите кнопку настроек в хедере
2. Настройте размер текста и масштаб
3. Переключите тему при необходимости
4. Включите высокий контраст для лучшей видимости

## 🔄 Сохранение настроек

Все настройки автоматически сохраняются в `localStorage`:
- `theme`: Текущая тема
- `fontSize`: Размер шрифта
- `scale`: Масштаб интерфейса
- `highContrast`: Режим высокого контраста

## 🎨 Кастомизация

### Добавление новой темы:
1. Добавьте CSS переменные в `:root`
2. Создайте селектор `[data-theme="new-theme"]`
3. Обновите `ThemeContext.tsx`

### Изменение цветов:
Отредактируйте CSS переменные в `index.css`:
```css
:root {
  --accent-primary: #your-color;
  --bg-primary: #your-bg-color;
}
```
