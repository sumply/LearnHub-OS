# Адаптивный дизайн Learn Hub

## Обзор

Проект настроен для корректного отображения на всех устройствах и размерах экранов: от мобильных телефонов (320px) до больших десктопов (1600px+).

## Основные улучшения

### 1. Viewport Meta Tag
- Обновлен для правильного масштабирования на всех устройствах
- Разрешен масштабирование до 5x для доступности

### 2. Адаптивные CSS переменные
Используются `clamp()` функции для плавного масштабирования:

- **Типографика**: `--font-size-xs` до `--font-size-4xl`
- **Отступы**: `--spacing-xs` до `--spacing-2xl`
- **Размеры контейнеров**: `--container-sm` до `--container-2xl`
- **Размеры элементов**: `--header-height`, `--logo-size`, `--button-padding-x/y`

### 3. Медиа-запросы

#### Брейкпоинты:
- **≤320px**: Очень маленькие экраны
- **321px-480px**: Маленькие мобильные
- **≤600px**: Мобильные устройства
- **601px-768px**: Планшеты (портрет)
- **769px-1024px**: Планшеты (альбом)
- **1025px-1280px**: Десктопы
- **1281px-1600px**: Большие десктопы
- **1601px+**: Очень большие экраны

#### Специальные запросы:
- Ландшафтная ориентация на мобильных
- Высокая плотность пикселей (Retina)
- Печать

### 4. Адаптивные компоненты

#### Header
- Адаптивные размеры логотипа и текста
- Гибкая компоновка для разных экранов
- На мобильных: вертикальная компоновка
- На планшетах: горизонтальная с переносом

#### NavBar
- Горизонтальная прокрутка на мобильных
- Адаптивные размеры кнопок
- Гибкая сетка на больших экранах

#### Main Shell
- Адаптивные отступы и размеры
- Плавное изменение ширины
- Адаптивные скругления углов

## Использование

### В компонентах

Используйте CSS переменные вместо фиксированных значений:

```tsx
// ❌ Плохо
<div style={{ fontSize: '2rem', padding: '1.5rem' }}>

// ✅ Хорошо
<div style={{ fontSize: 'var(--font-size-xl)', padding: 'var(--spacing-lg)' }}>
```

### В стилях

Используйте `clamp()` для плавного масштабирования:

```css
/* ❌ Плохо */
font-size: 1.5rem;

/* ✅ Хорошо */
font-size: clamp(1.25rem, 1.1rem + 0.75vw, 1.875rem);
```

### Утилитные классы

```tsx
<div class="container-lg p-md">
  <h1 class="text-3xl mb-lg">Заголовок</h1>
  <div class="grid-responsive gap-md">
    {/* Карточки */}
  </div>
</div>
```

## Лучшие практики

1. **Всегда используйте адаптивные переменные** вместо фиксированных значений
2. **Тестируйте на реальных устройствах**, а не только в эмуляторах
3. **Проверяйте ландшафтную ориентацию** на мобильных
4. **Используйте утилитные классы** для быстрой разработки
5. **Проверяйте читаемость** на всех размерах экранов
